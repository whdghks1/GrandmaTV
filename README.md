# 할머니 TV (GrandmaTV) — Galaxy A31 테스트용

MBC 공식 **엠빅라이브 전원일기** 페이지를 Android WebView로 열어 주는 개인용 시청 보조 앱입니다. 영상 파일이나 스트림을 추출/재배포하지 않습니다.

## v0.2.1 검은 화면 긴급 수정
- Galaxy A31에서 v0.2.0 이후 검은 화면 제보: 비디오 CSS 강제 확대 기능을 비활성화/제거했습니다.
- v0.1에서 재생되던 기본 WebView 화면 표시를 복구하는 안전 모드입니다.
- Skip Ad 자동 클릭 시도는 유지하나, 영상 확대는 더 안전한 방식을 찾을 때까지 보류합니다.
- 앱을 재빌드/재설치하여 방송이 다시 표시되는지 확인이 필요합니다. 실제 기기 검증 전입니다.

## v0.2.0 변경사항 (기록) (Galaxy A31 실기기 재검증 필요)
- Android WebView가 렌더링한 **최상위 페이지의 HTML video**를 탐지하면 4:3 영상 비율을 보존한 채 화면 전체에 배치합니다. 실제 MBC 플레이어가 cross-origin iframe 내부에 있을 경우 웹 플랫폼 보안 정책상 접근할 수 없어 기존 웹페이지가 그대로 보일 수 있습니다.
- 화면에 **명시적인 Skip Ad / 광고 건너뛰기 버튼**이 나타나고 활성화되어 있는 경우에만 1.5초 간격으로 찾고 자동 클릭을 시도합니다. 광고 차단/스트림 변경/재생 전 광고 우회 기능은 없습니다. iframe이 다른 출처이면 버튼을 찾지 못할 수 있습니다.
- 해당 전체 화면 토글은 v0.2.1에서 검은 화면 문제 대응으로 제거했습니다.
- 기존 광고 종료 뒤 본방송 자동 재생과 30초 터치 잠금 동작을 유지하도록 설계했습니다.
- 중요한 주의: 영상 영역 확대와 광고 건너뛰기는 **아직 A31 실기기에서 검증하지 않았습니다.** 사이트 구조가 달라지면 기능이 작동하지 않을 수 있습니다.

## 동작
- 실행 시 `https://onair.imbc.com/MbicPlay?channelid=43` 자동 방문
- 가로 화면, 몰입형 전체 화면, 사용 중 화면 꺼짐 방지
- 30초 후 화면 터치 차단 (의도하지 않은 영상 중단·페이지 이동 방지)
- 터치 차단 중 **화면 왼쪽 위 약 92dp 영역을 4초간 누른 뒤 손을 떼면** 보호자 메뉴 표시
- 잠금을 풀면 30초간 페이지 조작 가능; 보호자 메뉴에서 새로고침/Chrome 실행/종료 가능
- Android 뒤로 가기 무시. 홈 제스처/전원 버튼/전화 수신은 OS가 제어하며 완전 키오스크 아님.

## 프로젝트 열기 & APK 빌드
1. Mac 터미널에서 압축 해제한 프로젝트 폴더로 이동해 `./prepare-mac.sh` 실행. (공식 Gradle wrapper jar 다운로드, 최초 1회 인터넷 필요)
2. Android Studio → **Open** → `GrandmaTV` 폴더 선택.
3. Android Studio가 Gradle 플러그인과 JDK 17을 다운로드/동기화하도록 허용.
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)** 선택.
5. `app/build/outputs/apk/debug/app-debug.apk`를 Galaxy A31에 설치.
6. 휴대폰에 최신 **Android System WebView** 및 Chrome, Wi-Fi 연결 준비.

소스 내 `targetSdk = 32`는 Galaxy A31(Android 10~12) 로컬 테스트를 위한 선택입니다. Google Play 배포용이 아니며, 배포 시 최신 SDK와 edge-to-edge 대응을 포함해 갱신해야 합니다.

## 꼭 먼저 테스트할 것
1. 공식 MBC 사이트 영상이 Galaxy A31 **WebView에서 재생되는지** 확인 (사이트 정책/DRM 등에 따라 실패 가능).
2. 자동 재생이 안 된다면 일단 보호자 메뉴로 잠금 해제하고 페이지의 재생 버튼을 터치. 앱의 자동 재생 허용 설정은 웹사이트의 정책/플레이어 동작을 우회하지 않습니다.
3. 플레이어 전체 화면, 30초 후 터치 방지, 보호자 해제, 전화 수신 테스트.
4. 전원일기는 실시간 편성으로 운영되므로 사이트 상황에 따라 채널 이용 불가/광고/재생 오류 등이 있을 수 있습니다.

## 주의
- 개인 휴대폰을 쓰므로 **휴대폰의 전화·긴급 통화 기능은 유지**됩니다. 화면 완전 고정/시스템 제스처 차단은 하지 않습니다.
- 앱을 켜두면 화면·네트워크가 유지되므로 배터리를 소모합니다. 병원 환경에서 충전/발열/소리 크기 관리 필요.
- 앱은 실제 영상 재생을 검증하지 않은 테스트용 프로젝트입니다. 연결 장애 자동 복구/영상 재생 상태 감지는 향후 개선 기능입니다.

## 빌드 상태
이 환경에는 Android SDK/Gradle이 없어 실제 APK 컴파일은 검증하지 못했습니다. 소스 프로젝트만 제공합니다.
