# GrandmaTV — 할머니 TV

Galaxy A31에서 **MBC 엠빅라이브 전원일기** 채널을 최대한 간단하게 시청하기 위한 개인용 Android 앱.

## v1.0.0 — 기능 개발 완료

- 앱 실행 시 MBC 전원일기 채널 자동 열기
- 광고 이후 방송 자동 재생: Galaxy A31 사용자 실기기 확인
- 가로 화면 고정 및 화면 꺼짐 방지
- 30초 뒤 터치 잠금, 실수로 페이지를 누르지 못하도록 차단
- 화면 왼쪽 위 92dp 영역을 4초 이상 누른 후 손을 떼면 보호자 메뉴
- 보호자 메뉴에서 30초 터치 해제, 새로고침, Chrome으로 열기, 앱 종료
- Android 뒤로 가기 무시. 전화/긴급 통화 등 OS 기능은 유지

이번 릴리스에서는 매 1.5초마다 실행되던 광고 건너뛰기 DOM 검사 및 진단 메뉴를 제거했습니다. 검증되지 않은 강제 영상 확대 기능도 포함하지 않습니다. MBC 웹페이지에 있는 오른쪽 배너는 그대로 보일 수 있습니다.

## 설치 및 빌드

1. 저장소를 clone한 뒤 Android Studio로 프로젝트 폴더 열기
2. Gradle wrapper jar가 없으면 macOS에서 `bash prepare-mac.sh` 실행
3. Android Studio에서 Gradle Sync
4. Build → Build APK(s)
5. `app/build/outputs/apk/debug/app-debug.apk`를 Galaxy A31에 설치

설정: Android 최소 API 29, JDK 17, Gradle 8.7, Android Gradle Plugin 8.6.1.

## 사용상의 주의

- 시작 시 광고가 표시될 수 있고, 라이브 스트림 로딩에는 시간이 걸릴 수 있습니다. 광고 Skip 자동화는 사용하지 않습니다.
- 영상 원본 비율과 MBC 웹페이지 배치는 유지합니다.
- 완전 키오스크 앱이 아니며 Android 시스템 제스처는 여전히 사용할 수 있습니다.
- 장시간 재생 시 배터리·발열·충전 상태, 병실의 적절한 음량을 점검하세요.
- MBC 사이트가 바뀌면 동작이 달라질 수 있습니다.
- **연속 장시간 사용, 전화 수신 후 복귀, v1.0.0 재빌드 APK에 대한 회귀 테스트는 아직 완료되지 않았습니다.**

영상 콘텐츠 및 라이브 스트림을 추출하거나 재배포하지 않고 MBC 공식 웹페이지를 표시합니다.
